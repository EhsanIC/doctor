Project: Doctor Management & Simple Appointment Booking System

USER ROLES

1. Management
2. Doctor
3. Regular User

ADMIN CAPABILITIES

Specialty Management

- Add specialty
- Edit specialty
- Delete specialty
- Example specialties: Cardiology, Dermatology, Neurology, Orthopedics

Doctor Management

- View list of doctors
- Approve doctor
- Reject doctor
- Deactivate doctor

Doctor Profile Editing

- Edit image
- Edit specialty
- Edit description
- Edit status

DOCTOR CAPABILITIES

Registration

- Doctor can register, but cannot access the panel directly until approved by admin

Complete Profile
Fields:

- Name
- Mobile number
- Image
- Medical system code (license number)
- Specialties
- Address
- Description
- Working hours

Appointment Management

- View list of appointments
- Approve appointment
- Cancel appointment

REGULAR USER CAPABILITIES

- View approved/verified doctors
- Book an appointment

Book Appointment - Fields:

- Date
- Time
- Description/notes
